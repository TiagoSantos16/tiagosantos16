Selected work

sam2_unet_osm_lulc.py

Adapting SAM2-UNet for High-Resolution LULC

Fine-tuned SAM2, a large foundation model, for high-resolution land cover segmentation. During training, OSM road vectors act as a distance-transform soft target, so the network learns the structure of roads and infrastructure. That auxiliary branch is removed after training, so the deployed model runs on plain RGB imagery and needs no extra data at inference. The peer-reviewed paper reports strong Boundary IoU on thin features, plus a zero-shot UAV test shot in Portugal.

[ PyTorch · SAM2 · U-Net · GeoTIFF ]

master_thesis_models.py

Foundation Models for Earth Observation

A SAM2-UNet architecture I adapted for semantic segmentation of satellite imagery. I evaluated it on land cover maps with spatial metrics (mIoU, Boundary IoU), which measure boundary precision rather than overall agreement. It's the code behind my master's thesis.

[ PyTorch · SAM2 · U-Net · mIoU ]

[ github ] [ pdf ]

branchgpt.py

BranchGPT: Tree-Based AI Conversational Agent

A chatbot architecture that keeps the conversation in a tree instead of one long history. Each topic gets its own branch, so a clarification question doesn't pollute the main thread. I built it to stop the "context bleeding" and hallucinations you get with long, linear chat logs. Not finished yet.

[ LangGraph · FastAPI · PostgreSQL · Docker ]

[ demo ] [ github ]

afterk_disaster_evaluator.py

Afterk Disaster Evaluator: Post-Storm Recovery Dashboard

A dashboard for emergency teams and municipalities after a bad storm. It ingests satellite and aerial images, runs change detection to flag newly damaged zones, and tracks recovery over the following months: which areas are done, in progress, or still pending. Not finished yet.

[ Python · Change Detection · QGIS · Streamlit ]
